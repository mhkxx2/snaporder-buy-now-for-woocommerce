# SnapOrder Buy Now for WooCommerce

**SEO tagline:** Add Buy Now quick-order checkout and chat-order buttons on WooCommerce product pages, plus a floating chat help button.

SnapOrder speeds up product-page conversions with an express Buy Now modal, chat-order CTA, sticky Buy Now bar, and configurable floating chat button.

## Features

- Buy Now quick-order modal (variation + qty + coupon + shipping estimate)
- Chat-order button with message templates
- Floating chat help button (include/exclude rules)
- Sticky Buy Now bar
- Meta Pixel / GTM-friendly tracking hooks
- WooCommerce admin settings panel

## Installation

1. Copy this folder to `wp-content/plugins/snaporder-buy-now-for-woocommerce`
2. Activate **SnapOrder Buy Now for WooCommerce**
3. Configure store chat number and buttons under **WooCommerce → SnapOrder Buy Now**

## Requirements

- WordPress 5.8+
- PHP 7.4+
- WooCommerce 5.0+
