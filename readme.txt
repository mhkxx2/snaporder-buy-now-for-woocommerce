Add Buy Now quick-order checkout and chat-order buttons on WooCommerce product pages, plus a floating chat help button.

== Description ==

**SnapOrder Buy Now for WooCommerce** turns product pages into high-converting express checkout surfaces. Shoppers can place a Cash on Delivery (or quick) order from a modal without visiting the cart, or start a chat-order conversation with your store number — without friction.

SnapOrder is built for stores that sell with phone confirmation, COD, and chat-assisted sales — common in GCC and emerging ecommerce markets — while remaining useful for any WooCommerce shop that wants a faster “Buy Now” path.

= Why store owners use SnapOrder =

* Reduce checkout drop-off with a one-page Buy Now modal
* Capture name, phone, quantity, variation, coupon, and shipping estimate in one flow
* Offer a chat-order button next to Buy Now for assisted selling
* Show a floating chat help button sitewide or on selected pages
* Track funnel events with Meta Pixel / GTM-friendly hooks

= Core features =

* **Buy Now quick-order modal** on single product pages
* **Variation-aware** quantity, price, and attribute handling
* **Shipping estimate** inside the modal
* **Coupon support** in the quick-order flow
* **Chat-order button** with configurable message template placeholders
* **Floating chat button** (position, label, include/exclude pages)
* **Sticky Buy Now bar** for mobile / desktop conversion recovery
* **Admin settings** under WooCommerce
* **Tracking-ready** events for begin_checkout / lead style funnels

= Perfect for =

* COD-first stores
* Phone / chat assisted sales teams
* High-intent product pages that need express checkout
* Electronics, appliances, and catalog stores with variation products

= Template placeholders =

Chat message templates support tokens such as `{product_name}`, `{qty}`, `{price}`, `{link}`, and `{page_url}` (depending on context).

== Installation ==

1. Upload `snaporder-buy-now-for-woocommerce` to `/wp-content/plugins/`
2. Activate **SnapOrder Buy Now for WooCommerce**
3. Open **WooCommerce → SnapOrder Buy Now**
4. Enter your store chat number and message template
5. Configure floating button / sticky Buy Now options
6. Test on a product page

== Frequently Asked Questions ==

= Does this replace the WooCommerce cart? =

No. It adds an express Buy Now path and chat-order option. Standard cart/checkout remain available.

= Can I customize button labels and floating button text? =

Yes, from the plugin settings screen.

= Is WooCommerce required? =

Yes.

= Can I exclude the floating button from checkout? =

Yes. Use the floating button display rules / exclude pages settings.
